MTR Analytics Portal: AI-Assisted Defect Diagnostics

An autonomous product combining PySpark ETL pipelines, S3 data lakes, and LLM-powered natural language Q&A to enable operators to query Fulfillment Center transfer data and surface defect root causes in plain language, replacing manual analysis.

Role: Led 0-to-1 product design, architecture, and cross-functional delivery with RBS Sciences, Engineering, and Operations.

LLM Integration Generative AI Automated Diagnostics Data Pipeline Autonomous Agents

System Architecture

Standardizes operational anomaly detection by passing FC transfer diagnostic streams through LLM-powered reasoning and validation filters, eliminating manual case-by-case review bottlenecks.

Core Technical Components

Data Pipeline: Raw Transfer → Insights

PySpark ETL jobs extract FC transfer records from operational data sources, aggregate by defect patterns, and stage in S3 data lakes for LLM ingestion.

LLM Semantic Understanding

Large language model converts complex infrastructure diagnostic signals into formatted narrative insights, enabling operators to query data in natural language.

Hybrid Decision Engine

Pairs deterministic business constraints (e.g., facility capacity rules) with dynamic ML thresholds to route autonomous remediation actions safely and securely.

Product Experience

Operators can ask questions like:

  • "What are the top 5 root causes of manual transfers this week across FC North?"
  • "Which SKUs have ping-pong behavior in the last 30 days?"
  • "Show me same-day in/out patterns for this region."

The agent interprets natural language, queries the processed transfer dataset, and surfaces structured insights with recommended remediation actions.
